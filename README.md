# Linear Algebra Interactive Laboratory (JupyterLite)

Newton School of Technology | Mathematics-3 (Algebra + Geometry + Computation)

Interactive courseware powered by **JupyterLite** and **WebAssembly (Pyodide)**.
Students can run and edit 24+ dynamic simulations directly in their web browser with **zero installation, zero cloud costs, and unlimited duration**.

## 📐 Included Modules & Interactive Simulations

1. **System of Linear Equations (2D & 3D)**: Dynamic sliders for slopes, intercepts, and matrix coefficients.
2. **3D Plane Simulator**: Visualize unique point solutions, open-book lines of intersection, and parallel planes with 3D rotation.
3. **Linear Combinations & Span**: Explore vector addition, parallelogram rule, and span synthesis.
4. **Multidisciplinary Vector Applications**: RGB color vector mixing, audio vector synthesis, and image convolution transformations.

---

## ⚙️ How It Works

- **Engine**: Runs Python (NumPy, Matplotlib, Plotly, SymPy, ipywidgets) **entirely inside the student's browser tab** using WebAssembly.
- **Scalability**: Can handle 500 to 50,000+ concurrent students without server overload or timeouts.
- **Hosting**: 100% Free on GitHub Pages with automatic deployment via GitHub Actions.
